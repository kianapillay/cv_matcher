# CV Matcher

An ai-powered CV screening application built with Python and Streamlit.

## Overview

This application allows users to:
- Upload a CV as a PDF.
- Extract text from the document.
- Identify technical skills.
- Compare CV skills against job descriptions.
- Calculates a match score.
- Highlights missing skills.
- Generates automated feedback for candidate.

## Features
- PDF CV upload.
- Skill Extraction.
- Job Description Analysis.
- Skill Gap Detection.
- Match Scoring.
- Interactive Streamlit Interface.

## Tech Stack
- Python
- Streamlit
- PDFPlumber 
- Scikit-learn
- Git & GitHub

## Installation

Clone the respository:
```bash
git clone https://github.com/kianapillay/cv_matcher.git
```

Install dependencies:
```bash
pip install -r requirements.txt
```

Run the application:
```bash
streamlit run app.py
```
